## Cómo trabajar

- **Google Colab:** abre el enlace del notebook; ejecuta las celdas en orden. Los cambios dentro de Colab no se guardan automáticamente en GitHub.
- **Local:** clona el repositorio, prepara un entorno con `numpy`, `pandas`, `matplotlib`, `scikit-learn`, `jupyter` y abre el archivo `.ipynb` en JupyterLab o VS Code.
- **Experimentación:** modifica los parámetros sugeridos, ejecuta de nuevo desde el inicio y compara resultados.
- **Organización:** cada notebook conserva un objetivo concreto, un dataset reproducible, explicaciones, gráficos y pequeñas actividades.

Las definiciones y conexiones conceptuales permanecen en el vault de Obsidian; aquí conservamos los laboratorios ejecutables.
